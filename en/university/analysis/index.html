Mathematical Analysis

Analysis studies the mathematics of continuous quantities. Humanity discovered a crack in numbers themselves - some lengths cannot be expressed by rational numbers, and this is where real numbers were born.

Real Number Axioms: Accepting the "Night of Continuity"

Completeness axiom: Every non-empty set bounded above has a least upper bound. This is not construction, but acceptance - declaring that the real line has no gaps.

Five Equivalent Propositions

1. Supremum Principle

Non-empty sets bounded above have supremum

2. Monotone Convergence

Monotone bounded sequences converge

3. Nested Intervals

Nested intervals with length → 0 intersect at one point

4. Bolzano-Weierstrass

Every bounded sequence has a convergent subsequence

5. Cauchy Criterion

Terms getting closer to each other must converge

Important Theorems

Intermediate Value Theorem

Continuous function on closed interval takes every value between endpoints.

Extreme Value Theorem

Continuous function on closed interval attains maximum and minimum.

Fundamental Theorem of Calculus

Differentiation and integration are inverse operations.
