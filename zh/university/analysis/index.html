数学分析

分析学研究连续量的数学。人类发现数本身有一条裂缝——有些长度不能被有理数表达，而这就是实数的诞生地。

实数公理：接受那片"连续性黑夜"

完备性公理：任何有上界的非空实数集，都有上确界。这不是构造，而是承认——宣告实数线没有缺口。

完备性的五条等价命题

1. 确界原理

有上界的非空实数集必有上确界

2. 单调有界定理

单调递增且有上界的序列必然收敛

3. 区间套定理

闭区间套长度趋于零则交于唯一一点

4. B-W定理

任何有界序列必有收敛子列

5. 柯西准则

序列项彼此越来越近则必收敛

核心概念层级

L1 实数（完备性）
L2 序列（ℕ → ℝ）
L3 函数（ℝ → ℝ）
L4 函数列（ℕ → 函数空间）

重要定理

介值定理

若 $f$ 在闭区间上连续，则它在两端之间取遍每一个值。

极值定理

闭区间上的连续函数，必在某处取到最大值和最小值。

微积分基本定理

微分和积分锁成一对逆运算。
